# @amlplugins/shopify-app-bridge

Native `@shopify/app-bridge` SDK re-exported under the `@amlplugins` namespace.

> Shopify App Bridge — embedded admin app framework with iframe-bridged actions, navigation, toast, resource picker.

## Install

```bash
npm install @amlplugins/shopify-app-bridge
```

## Use

```ts
import { /* named exports from @shopify/app-bridge */ } from "@amlplugins/shopify-app-bridge";
// or
import sdk from "@amlplugins/shopify-app-bridge";
```

This package additionally re-exports `@shopify/app-bridge-react` under the `secondary` namespace.

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
